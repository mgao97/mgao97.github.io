# 2026-09-26

## 个人主页 index.md 排版修正（Selected / Other Publications）

**问题**：`.pub-row` 原来是 `grid-template-columns: 170px 1fr` 且每条论文独占一个整行，容器 900px 全宽，7 条纵向堆叠 → 整块撑满页面、正文列约 670px，视觉拥挤无留白。

**用户决策**（AskUserQuestion）：Selected Publications 改为**双列卡片网格**；Selected 与 Other 统一包进 `.info-card`。

**改法**：
- `stylesheet.css`
  - 新增 `.pub-grid` / `.other-grid`：`repeat(2, minmax(0,1fr))`，`gap: 18px 24px`；7 条排成 4 行、末行留空位 → 天然留白。
  - `.pub-row` 变为卡片：`118px minmax(0,1fr)`、`align-items: center`（缩略图是 2.4:1 banner，不裁剪，纵向居中）、浅底 + 边框 + hover 变边框色。
  - 卡片内字号下调：title 15px / authors、venue 12.8px / links 12.5px，适配窄栏。
  - `.other-pub-item` 从「下划线分隔列表」改为同样的浅底卡片。
  - `.info-card` padding 改为 `12px 20px 18px`，margin `20px 0`。
  - 768px 断点：两栏降为单栏，缩略图放大到 140px。
- `index.md`：`<h2>Selected Publications</h2>` 与其 7 个 `.pub-row` 包进 `<section class="info-card">` + `<div class="pub-grid">`；Other Publications 同样处理（`.other-grid`，9 条）。

**验证方式**：本地 `python3 -m http.server 8765` + `preview.html`（marked.js 渲染 index.md），通过 present_files 传 localhost URL 实时预览。注意：headless Chrome 截图会被沙箱 SIGKILL（exit 137），无法自行出图。

## 修订（同日）：双列方案被否，改回「一行一条 + 收窄行宽」

用户对双列卡片的反馈是「不好看」。最终版式：

- **仍是一行一条论文**（`.pub-row`），但行宽收窄到 `max-width: 720px`，卡片内宽约 832px → 右侧保留约 90px 空白，既避免撑满页面又维持单条一行的易读性。
- `.pub-list` / `.other-list` 由 grid 退回普通 block 容器（类名也从 `pub-grid`/`other-grid` 改过来，避免「grid 不是 grid」的误导）。
- 缩略图 118px → **176px**；字号回补：title 16px / authors、venue 13.5px / links 13px。
- `.other-pub-item` 退回下划线分隔的纯文本列表（堆叠 9 个边框盒子太重），保留 `max-width: 760px`。
- 768px 断点：`.pub-row` 转单列、`max-width: none`。

**可复用的做法**：改完用 `python-markdown`（装在 `~/.workbuddy/binaries/python/envs/default`）把 index.md 渲染 + stylesheet.css 内联，输出 `preview_static.html` 到仓库根目录（这样 `images/`、`data/` 相对路径可用），再 present_files 交给用户看。不依赖后台服务进程，比 `python3 -m http.server` 可靠——后者在本会话中随轮次结束被回收，用户反馈「预览看不了」。
